# 智诉决策平台前端

Vue 3 + Vite产品工作台，对应融合V3.0，覆盖：

- 客诉退款工单、协同队列、高级检索与策略中心；
- 评测运行、A/B、发布门禁、漂移与成本预算；
- 零信任安全事件、Critic检测与DLP脱敏；
- 意图路由、纠正反馈与死信恢复；
- 实时语音控制台、容量预算和客服陪练；
- 订单/决策/退款回执对账与统一版本治理。

## 本地开发

安装依赖后运行：

    npm run dev

默认访问 http://127.0.0.1:5173，并将/api代理到http://127.0.0.1:8001。

## 生产构建

    npm run build

构建脚本使用Vite程序化配置，避免Windows中文、空格或特殊字符路径导致配置加载失败。产物输出到dist目录。
